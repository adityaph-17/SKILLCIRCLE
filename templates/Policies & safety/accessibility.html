Accessibility

Last updated: October 2026

1. Our Accessibility Commitment

SkillCircle aims to make its platform accessible and usable for as many people as possible, including people who use assistive technologies.

We aim to follow widely accepted accessibility practices and accessibility principles, including the principles of the Web Content Accessibility Guidelines (WCAG), where reasonably possible.

2. Accessible Design

We try to design SkillCircle pages so that information, navigation and important actions are easy to understand and use.

This includes clear headings, readable text, simple navigation, visible buttons and responsive layouts.

3. Keyboard Navigation

Users should be able to navigate important parts of the website using a keyboard without depending only on a mouse.

We aim to keep interactive elements such as links, buttons and form fields accessible through normal keyboard navigation.

4. Screen Readers and Assistive Technologies

We aim to use meaningful headings, labels and page structures so that screen readers and other assistive technologies can understand the content more easily.

5. Text, Colour and Contrast

SkillCircle uses readable text sizes and sufficient contrast between text and backgrounds wherever possible.

Important information should not depend only on colour to communicate its meaning.

6. Images and Alternative Text

Meaningful images should have appropriate alternative text so that users who cannot see the image can understand its purpose.

Decorative images may not require alternative text.

7. Forms and Labels

Forms such as registration, login, profile and skill sharing forms should provide clear labels and instructions.

Error messages should provide understandable information so users can identify and correct problems.

8. Mobile Accessibility

SkillCircle is designed to work on different screen sizes, including desktop computers, tablets and mobile devices.

Users should be able to access important content and controls without unnecessary horizontal scrolling.

9. Videos and Multimedia

If SkillCircle provides videos or other multimedia content, we aim to provide accessible controls and suitable alternatives where reasonably possible.

10. Third-Party Content

Some content or services may be provided by third parties. SkillCircle cannot always control the accessibility of third-party websites, tools or services.

We encourage users to contact the relevant third-party provider when an accessibility problem is caused by an external service.

11. Known Limitations

SkillCircle is a developing platform. Some pages, features or third-party components may not yet provide a fully accessible experience.

We may improve accessibility as the platform develops and as accessibility issues are identified.

12. Report an Accessibility Problem

If you experience an accessibility problem while using SkillCircle, please report it to us.

When reporting an issue, please provide:

  • The page or feature where the problem occurred.
  • A description of the accessibility problem.
  • The device or browser being used, if relevant.
  • Any assistive technology involved, if relevant.

13. Alternative Access

If you are unable to access important information or use an important feature because of an accessibility problem, please contact SkillCircle. We will try to provide a reasonable alternative where possible.

14. Changes to This Accessibility Statement

We may update this Accessibility Statement when the platform, accessibility practices or available features change.

The updated date at the top of this page will show when the statement was last changed.

15. Contact

If you have an accessibility question, request or complaint, please contact the SkillCircle team through the available contact method on the platform.
